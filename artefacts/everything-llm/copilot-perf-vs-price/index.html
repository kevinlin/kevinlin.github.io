Coding Score vs. Blended Price

What a million tokens costs on each Copilot model once its four billing rates are weighted the way an agentic coding session actually uses them, plotted against the share of SWE-Bench Pro tasks that model resolves. The price axis is logarithmic: Fable 5 costs 45× what Luna does per blended million tokens. Dashed lines join one model to its second published rate: the long-context tier, or Opus 4.8’s fast mode.

    Data table

    Price. GitHub meters Copilot per token at four rates: fresh input, cached input, cache write and output. A single price therefore needs a token mix, and the blended figure weights those rates the way a long agentic coding session consumes them — 14% fresh input, 70% cached input, 8% cache write, 8% output. Cached reads dominate because an agent re-sends its whole context every turn and only the delta is charged at the fresh rate. The shares sum to 100%, so the result is a true weighted average dollar-per-million-tokens. Where a vendor charges nothing for cache writes, that 8% is billed as fresh input instead. Copilot meters all of it in AI credits at 1 credit = $0.01, so the credit column is the dollar figure times 100. Points use the default price tier; the second point on each dashed line is the long-context tier, priced from the same mix and labelled with the input-token count above which it takes over.

    Score. SWE-Bench Pro resolve rate: the share of 731 public tasks where the agent’s patch makes the failing tests pass without breaking any that already passed. Hollow markers come from Scale’s independently run leaderboard, which uses its own SWE-agent scaffold with uncapped cost and a 250-turn limit; filled markers are vendor-reported at each model’s best published configuration. The two are not like-for-like — a hollow point below a filled one may be measuring the scaffold as much as the model, and every Claude model older than Opus 4.7 has only a Scale figure. GPT-5.4 also appears on Scale’s board at 59.1% (xHigh, mini-swe-agent); the vendor number is plotted here. Vendors also restate each other’s numbers: the GPT-5.6 launch page puts GPT-5.5 at 59.4% and Fable 5 at 80%, against the 58.6% and 80.3% each reported at its own launch. Launch figures are plotted.

    Not shown. Twelve priced Copilot models have no published SWE-Bench Pro result and so cannot be placed: Claude Sonnet 4.6, GPT-5.4 mini, GPT-5.4 nano, GPT-5 mini, Gemini 3.7 / 3.6 / 3.5 Flash, Grok 4.6, Kimi K2.7 Code, Raptor mini, MAI-Code-1-Flash and MAI-Code-1.1-Flash. Claude Haiku 4.5, Claude Sonnet 4 and Claude Sonnet 4.5 do have Scale figures, but are left off this chart. Code completions and next edit suggestions are unbilled. Copilot code review does not disclose its model, so it has no rate to quote. Sources: GitHub Copilot models and pricing and Scale SWE-Bench Pro (public dataset), both retrieved 17 August 2026, plus vendor launch reporting for the filled points — Terra and Luna come from the coding table on OpenAI’s GPT-5.6 page.
