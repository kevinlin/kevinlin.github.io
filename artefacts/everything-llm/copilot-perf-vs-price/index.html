Intelligence Index vs. Blended Price

What a million tokens costs on each Copilot model once its four billing rates are weighted the way an agentic coding session actually uses them, plotted against that model’s score on the Artificial Analysis Intelligence Index v4.3. Only models this Copilot subscription can call are shown. The price axis is logarithmic: GPT-6 Astra and Opus 4.8 in fast mode each cost 45× what Luna does per blended million tokens. Dashed lines join one model to its other published rates: the long-context tier or Opus 4.8’s fast mode.

    Price. GitHub meters Copilot per token at four rates: fresh input, cached input, cache write and output. A single price therefore needs a token mix, and the blended figure weights those rates the way a long agentic coding session consumes them — 14% fresh input, 70% cached input, 8% cache write, 8% output. Cached reads dominate because an agent re-sends its whole context every turn and only the delta is charged at the fresh rate. The shares sum to 100%, so the result is a true weighted average dollar-per-million-tokens. Where a vendor charges nothing for cache writes, that 8% is billed as fresh input instead. Copilot meters all of it in AI credits at 1 credit = $0.01, so the credit column is the dollar figure times 100. Points use the default price tier; the next point on each dashed line is the long-context tier, priced from the same mix and labelled with the input-token count above which it takes over.

    Score. Artificial Analysis Intelligence Index v4.3, taken from Artificial Analysis’ model comparison between 11 and 13 September 2026. The index is a composite of evaluations Artificial Analysis runs itself, so every model is measured the same way. It is a general intelligence score, not a coding benchmark, and v4.3 scores can’t be compared with earlier index versions. Each reasoning-effort setting is scored separately. Every model is plotted at its highest-scoring setting, which the data table names: max for most models, xhigh for GPT-5.5 and GPT-5.3-Codex, and high for Grok 4.6, whose xhigh setting scores a little lower at 44.27. Copilot may run a model at a lower effort, so read each point as that model’s ceiling.

    Not shown. The chart is limited to the models the Copilot /models API returned for this subscription on 13 September 2026. GitHub prices several more that this plan can’t call, so they are off the chart even where a score exists: Claude Fable 5.1, Claude Fable 5, GPT-5.4, Gemini 3.8 Flash and Grok 4.5 among them. Of the models this plan can call, GPT-5 mini, GPT-5.4 mini and MAI-Code-1.1-Flash are not in the Artificial Analysis comparison used here, so they cannot be placed. Claude Haiku 4.5 is left off this chart. Code completions and next edit suggestions are unbilled. Copilot code review does not disclose its model, so it has no rate to quote.
