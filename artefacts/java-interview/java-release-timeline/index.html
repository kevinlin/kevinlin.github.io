OpenJDK feature releases · Sep 2018 – Mar 2026

Java release timeline

Every six months since Java 10, OpenJDK ships a feature release. LTS releases plot above the axis on round markers; interim feature releases plot below it on square ones. Each card carries the headline features; pick one to open the detail panel with the purpose and working code behind them.

Scroll sideways → Select a release for the detail panel Arrow keys move between releases

Scope Developer-facing language, API and tooling changes rather than every JEP. A feature marked preview needs --enable-preview at both compile and run time, and its syntax can change or be withdrawn — string templates, previewed in Java 21 and 22, were dropped rather than finalised.
Support Java 11, 17, 21 and 25 are the long-term-support releases in this range. Interim releases are superseded by the next feature release six months later. As of August 2026, Java 26 is the latest feature release and Java 25 the latest LTS.
Sources openjdk.org JDK project pages 11 through 26, plus the Java SE API documentation for the finalised APIs.
